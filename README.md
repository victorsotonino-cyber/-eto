# Nexus Ticket & Moderation Bot

Sistema profesional de tickets y moderación para Discord.

Incluye:
- Panel de tickets con menú de selección.
- Soporte, Rewards, Reportes y Otros.
- Cerrar, reabrir, reclamar, añadir, quitar, renombrar, transcript y eliminar.
- Configuración de categoría, rol Staff y logs.
- Ban, unban, kick, timeout, untimeout, warn, warnings, clearwarns.
- Clear, lock, unlock, slowmode y nick.
- Userinfo y serverinfo.
- Persistencia local.
- Health check para hosting.

Variables:
DISCORD_TOKEN
CLIENT_ID
GUILD_ID (opcional)
PORT (opcional)
TICKET_IMAGE_URL (opcional)

Comandos:
ticket panel, ticket setup, ticket close, ticket reopen, ticket delete, ticket claim, ticket unclaim, ticket add, ticket remove, ticket rename, ticket transcript, ticket list
modlog set, modlog off
ban, unban, kick, timeout, untimeout, warn, warnings, clearwarns, clear, lock, unlock, slowmode, nick, userinfo, serverinfo
